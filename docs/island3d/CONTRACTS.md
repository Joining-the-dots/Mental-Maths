# My Island 3D — build contracts (read this before writing any code)

Source designs in this folder: `art-bible.json` (look + audio), `island-architecture.json` (3D island, its 16 chunks), `spec-runner.json` (Debut Run), `spec-penalty.json` (Encore Shootout), `spec-kart.json` (Neon Grand Prix). Where a game spec and the art bible disagree about game MECHANICS, the game spec wins (the art bible's "leave game logic alone / don't draw boost pads" lines are superseded for the games). Where a game spec's *shell integration* differs from §2 below, §2 wins — it is what `world/games/shell.js` actually implements.

## 0. Rules for every builder
- **Do not deploy, push, merge or mirror anything.** Work only in your own git worktree, on a new branch named in your task (`i3d/<name>`). Commit there and report the branch name and commit hash.
- **Only create/edit the files your task owns.** If you need something from a file you don't own, code against the contract below and note the dependency in your report. Never edit `world/world-core.js` (rules, CATALOG, GAME_RULES), `index.html`, `sw.js`, `world/rewards-world.js` or `world/games/shell.js` unless your task explicitly owns it.
- **Three.js r170** comes only from the import map: ES modules use `import * as THREE from 'three'` (and `three/addons/...`); classic scripts receive THREE from the runtime (`SL3D.THREE`). **Never use `window.THREE`** — `index.html` also loads an old global r128 for a parked feature. WebGL2 only.
- **No downloaded or embedded assets.** Models are built from primitives; textures are drawn on canvases at runtime. Fonts (Google Fonts only): **Unbounded 600/800 + Outfit 400–800 for the island and the games; Bagel Fat One / Baloo 2 / Fredoka only on learning screens.** Sounds: the shell/SLSound names; music via SLMusic.
- **Original content only.** K-pop *inspired* staging/colour/energy — never real idols, groups, songs, lyrics, logos, fandom colours, real light-stick shapes or recognisable choreography. Kid-safe: cartoon tumbles, no injury/fire/explosions/scary faces; never flash faster than 2 Hz (`MAX_FLASH_HZ`); full-contrast LED chases light each bulb at most **1.5 Hz** (`SLIslandLook.LED_CHASE_HZ`); beat pulses ≤ 1.97 Hz at ±35% or less; a local bloom at most once per 1.5 s per item; honour reduced motion.
- **Words in textures:** only `SLIslandLook.SIGN_WORDS` (ENCORE, SHOWTIME, ON AIR, PHOTO, DANCE, PET COURSE, ISLAND) plus the child's own first name and initial, drawn through `K.signAtlas()` / `K.ledAtlas()`. No brands, logos, Hangul, "K-pop" or "idol".
- **Outlines:** architecture (houses, buildings, attractions, decor) has **no ink hull** — only the edit selection hull (Star Gold, 0.02 ↔ 0.03 u at 1.5 Hz). Characters (pets, accessories, avatar) keep a **0.009 u Midnight Ink** hull on MID/HIGH (`OUTLINE_KINDS`).
- **Pure logic stays pure.** Logic modules are classic UMD scripts (`window.X` in the browser, `module.exports` in Node) with no DOM and no THREE, and must pass Node 22 tests: run `"/c/Users/jamco/.local/node/node.exe" --test tests/*.test.js` from the repo root (the glob form is required). Put your tests in your own new test file(s). All existing tests must still pass unless your task explicitly replaces one.
- **Games never award or spend reward points.** Results go through `round.result()` and are validated by `GAME_RULES` (unchanged).
- Performance targets (art bible `performanceBudget`): 2019 iPad / mid Android at 60 fps, never under 30; capped pixel ratio; instancing; no PointLights/SpotLights; static shadow maps only on MID/HIGH.
- Syntax-check every JS file you write with `node --check` (ES modules: `node --check` works on `.mjs`; for `.js` ES modules use `node --input-type=module --check < file` or a dynamic import smoke test).

## 1. Shared 3D runtime (island chunks 1, 2, 8 provide it; games consume it)
Classic scripts under `world/island3d/`, loaded by `stage.js`.
- `window.SLIsland3D.boot(opts)` — island use (mount happens in the integration chunk).
- **`window.SLIsland3D.ensure()` → `Promise<SL3D|null>`** — loads three (via `window.slLoad3D()`), the kit and model/character scripts, runs the registered model factories, and resolves the shared `SL3D` object WITHOUT mounting an island scene. Safe to call many times (memoised). Resolves `null` if 3D is unavailable. Games' 3D views call this.
- `SL3D.THREE`, `SL3D.tier` ('LOW'|'MID'|'HIGH'), `SL3D.budget` (per-tier numbers from tier.js).
- `SL3D.kit(tier)` → `K` (geometry kit `K.G`, `K.template(ctx)`, `K.batch`, materials by key, `K.col(token)`), exactly as in `island-architecture.json` → `modelFactoryApi`.
- `SL3D.defineModels(category, factory(K))` — model registration (island chunks 4–8).
- `SL3D.make(id, st, tier)` → `THREE.Object3D` (a ready-to-add group for one catalogue item / kart; used by games and photocards).
- **`SL3D.makeRig(petId, acc, tier)` → `PetRig`** `{root, bones, sockets, setPose(pose), setShow(k), play(clip, t, opts), dispose()}`. Chunk 8 must ship built-in clips usable by games without actors.js: `'idle','walk','run','hop','jump','fall','slide','tumble','dizzy','dance','cheer','sad','sit','kick','drive'` (each a pure function of time; `opts.speed`, `opts.intensity`). Pet ids: `pet_puppy, pet_kitten, pet_bunny, pet_dragon`; `acc` = `{hat, neck, face, back}` → accessory ids from CATALOG (`acc_*`).
- `SL3D.makeAvatar({color, emoji}, tier)`, `SL3D.makeWand(colorHex, tier)`, `SL3D.makeFanBlob(seed, tier)` (crowd), `SL3D.make('kart_<x>', {}, tier)` (karts in LOCKED colours).
- **Games must still work if `SLIsland3D` / `makeRig` is missing** (load order, a failed chunk): fall back to a simple pet built from their own primitives in the same locked PETCOL colours.

## 2. Game shell hooks (implemented in `world/games/shell.js`; all optional)
`def` fields:
- `view3d: { src: 'world/games/<game>-3d.js' }` — an ES module exporting `create(mid, opts)` → view (or a Promise of one). `opts = { THREE, cfg, api, def, reduced, onFail(reason) }`. View: `{ canvas, frame(round|null, dt, alpha, phase, countT), resize(cssW, cssH), dispose(), setRound?(round|null, variant) }`.
  - The shell imports the module (after `window.slLoad3D()` resolves THREE) with an 8 s budget, creates the view when ready, inserts `view.canvas` UNDER the 2D canvas (which stays on top, transparent, as the tap target), and calls `frame()` every draw. In menu/tutorial/results/time-up it calls `frame(round|null, dt, 0, phase, 0)` at ~30 fps. Any throw or `onFail()` disposes the view and the SAME round continues in 2D. `alpha` = fixed-step interpolation fraction. `phase` ∈ menu | tutorial | countdown | playing | paused | results | timeup.
  - The view reads `round.state` (and any read-only getters the logic offers) and drains `round.events` (see below). It must never change logic state.
- `hud: { mount(mid, cfg, api) → { update(round, phase), dispose() } }` — optional HTML HUD layer (mounted once, updated every draw).
- `countIn: { beats, bpm, labels[] }` — beat count-in used for start AND resume (instead of `countdown` seconds).
- `controlsFor(cfg)` → pad list (instead of `controls`).
- `menuVariants(cfg)` → `[{id, name, icon, tip, locked, lockText, medal, best}]`, `menuVariantsTitle`, `menuVariantsLabel` — a game-owned variant list (e.g. penalty rivals). Selection is remembered in `localStorage 'slgVar:'+key` and does NOT call `cfg.onSelectVariant`.
- `menuOptions(cfg)` → `[{id, label, value, options:[{value, label, locked, note}]}]` + `setOption(cfg, id, value)` — chips on the menu (modes, toggles like Fan support / Easy Drive).
- `pbText(rec, variant, cfg)` → string for the menu's best line.
- `music: { track }` — with `window.SLMusic`: shell calls `play(track, {countInSec})` at round start, `menuMode(true/false)`, `pause(200)`, `resume(300)`, `stop(200)`; big-moment sounds duck the music.
- `resultsGlass: true` — results sheet becomes a glass panel over the 3D scene.

`round` fields:
- `events` / `wantEvents`: the shell sets `round.wantEvents = true` and `round.events = []` after `newRound`; the logic pushes plain objects (`{type:'bump', ...}`) **only while `wantEvents` is true** (so Node tests never accumulate); the shell empties `events` after every draw (views and the HUD read them during that draw).
- `countdown(countT, held, isStart)` each countdown step; `pauseReset()` on pause; `padState(id)` → `'' | 's1' | 's2' | 's3' | 'grey' | 'ready'` (pad glow); `summaryBadges()` → `[{text, kind: 'bronze'|'silver'|'gold'|'crown'|'ribbon'|'hint'}]`; `onFinish()` at the start of results.
- Unchanged: `step(dt, held)`, `input(id, down)`, `pointer?`, `done`, `hud()`, `result()`, `summaryTitle/Big/Text()`, `forceEnd()`, `autopilot()`, `autoHeld`, `render(ctx)` (the 2D fallback renderer — keep one), `dispose?`.
- Keys/pads held through the countdown are delivered as fresh `input(id, true)` presses at GO.

`cfg` fields passed by `rewards-world.js` launch: `variant, ownedVariants[{id,name}], pet {id, name, acc}, ball, stadium, kart, pb, tutSeen, reduced, muted(), toggleMute(), arcade{...}, onTutorialSeen, onSelectVariant, onResult(variant, res), onExit, user {name, color, avatar}, profileKey, day` (family-time-zone day key — use it for daily seeds). `GAMES[game].deps` = extra `world/games/*.js` classic scripts loaded after `shell.js` + `fx.js` and before the game file; `GAMES[game].tutKey` = the tutSeen key (bump it when a game's tutorial changes).

## 3. Audio
- `window.SLSound` (`world/sound.js`, island chunk 13): `make(cfg)` → `sound(name, vol, step)` with the same names/recipes as the shell's `makeSound` plus pet voices (`yip, mew, thump, trill`) and stereo pan; respects mute.
- `window.SLMusic` (`world/music.js`, island chunk 13):
  - `channel(opts)` → `{ play(track, {countInSec, clock?, bpm?}), menuMode(on), pause(ms), resume(ms), stop(ms), set(name, value), layer(name, on), key(semitones), drop(), sync(seconds) }` — every method safe to call in any state.
  - `SLMusic.duck(level, ms)`, `SLMusic.enabled()`, `SLMusic.setEnabled(on)` (🎵 toggle, `localStorage 'slMusic'`, try/catch), `SLMusic.island(context)` for `'island_day' | 'island_showtime' | 'shop'`, `SLMusic.stopAll(ms)`.
  - Tracks: `island_day, island_showtime, shop, course, penalty, kart`. If `audio/music/<track>.mp3` exists it loops it (bar-exact); otherwise the WebAudio "Pocket Band" synth plays an original pattern for that track. `course` with `{clock}` is BEAT-LOCKED: the band schedules from the given logic clock (seconds) so obstacles stay on the beat; `set('hype', 0..1)`, `set('fever', bool)`, `key(+n)`, `drop()` change layers. Music starts only after a user gesture, obeys mute, plays only on My Island and in its games.

## 5. Island scene contract (wave C — decided by the lead after waves A/B)
Built on what exists now: `world/island3d/{tier,stage,kit,grid3d,motion,env}.js`, `world/world-look.js`, the model files `models-{garden,home,fun,attractions,characters}.js` (read their headers: they document exactly what they need from the controller).
- **Mount API** (owned by `world/island3d/island3d.js`, which must ADD `mount` to the existing `window.SLIsland3D` object — never replace it): `SLIsland3D.mount({reduced, user:{name, color, avatar, seed}, skyline?, on:{tapItem(uid), tapPet(petId), tapAvatar(), tapLand(landId), tapCell(x, y), dragStart(uid), dragCell(x, y), dragEnd(), dragCancel()?, ready(), fail(reason)}})` → stage `{attach(el), sync(view), act(uid, name), emote(target, kind), setLit(uid, on), unlockLand(region) → Promise, debut(uid), storeFx(uid), showtime(on, {encoreMs}?), danceNow(), setAnchors(list), focusItem(uid), resetView(), frameItem(uid), setCovered(on), suspend(), resume(), setReduced(on), setUser(user), placement(state|null), info(), dispose()}` exactly as `island-architecture.json → integrationWithRewardsWorld` describes (`view` = `{placed, style, unlocked, pets, avatar, mode, selectedUid, placing, lit, world}`). v2: `user.seed` = the profile key (or its hash) — the child's own coastline and the home trim fallback `fnv(seed) % 2` (`view.style.variant` wins); `skyline: false` skips the mount hero shot (lab / QA fixtures); `act(uid, 'encore')` on a Concert Stage runs the model act, 8 s of Showtime (`showtime(true, {encoreMs: 8000})` — the host's identical call only re-arms it), the skyline eased toward the stage, and ignores re-taps on that stage while it runs; the child's Golden hour / Showtime choice returns afterwards. `SLIsland3D.debug.grid(on)` (and `?grid=1` under `SL_WORLD_TRIAL`) draws the edit grid in play mode.
- **Renderer**: the island takes `SL3D.lease('island', {...})` and renders through the lease's paced loop. When a game takes the renderer the island gets `onRevoke` (pause) and later `onResume` (re-parent `lease.canvas`, re-apply exposure/clear colour).
- **Batches**: one `K.batch(template, {material: SL3D.models[id] && SL3D.models[id].material})` per (id, stateKey); items placed with `{x, y, fp}` (the kit now resolves ground height itself via `SLGrid3D.baseY(id, x, y)`). Pass the same `material` hook to `K.instantiate`.
- **Animation handle `a`** passed to every model's `idle(a)`, `act(a, name)`, `show(a, k)`: `uid, id, t, dt, phase (SLMotion.phaseOf(uid)), rand, reduced, beat, bar, bpm (from SLMusic.clock() when present, else 100), show (0..1), lit (0|1, the island's lit memory), stateKey, template, batch (the ItemBatch), object (when instantiated), copyGeometry(part) → that copy's BufferGeometry for perCopy parts, basePositions(part) → Float32Array, pivot(name) → {set(rotDeg[], pos[], scale[])}, state(key, value), halo(name, on, sizeU, token), decal(on, token), emit(kind, anchorOrLocalPos, n, opts)` (COPY pos/opts — models reuse scratch objects), `sfx(name, vol, step)` (auto-panned by x), `pets: {active(), perform(kind, uid) → lead seconds (0 = no pet)}`, `shake(amp, dur)`, `squish()`, `music` (SLMusic.clock() or null). v2 (§9): `member` ('#hex' | null), `user` `{name (first name only), color, avatar}`, `bloom(anchor, sizeU, token) → bool`, `pets.active()` → the active pet's id or null, and `show` is the copy's own mix inside the env's 'city wakes up' ripple.
- **Ticking**: call `idle(a)` every frame for every placed copy whose model has an `idle` handler (models return false when idle has nothing to animate; under reduced motion call once after each sync). Call `show(a, k)` whenever the Showtime mix `k` changes (every frame during the blend) and once after add/restyle. Houses: also tick when `model.animated(stateKey)` is true.
- **Acts and sounds**: the controller owns the universal tap squish and its `'pop'`; model act handlers own every other cue of their act and must not play `'pop'` in their first 0.05 s. One live act per uid; a new tap restarts it.
- **Env** (v2, `SLIslandEnv.VERSION` 2): `SLIslandEnv.create(K, SL3D, {scene, renderer, unlocked, world, show, member, reduced, seed, name, tier, terrain, terrainMs?, city?, life?})` as documented in `env.js` → `{group, update(dt, t, showK?), beforeRender, attach, setLand, setPlaced, riseRegion, showtime(on, {reduced}), setShow(k), show (the Showtime mix models see; eases to 0 in edit), light, setEdit(on), aim, setConeMounts([{x, y, z}] | null), setMember(hex), setUser({name, color, seed}), setSeed(seed), setReduced, setQuality, invalidateShadows, lockedAt, heightAt(x, z), wakeAt(x, z) → 0..1, anchors, mode ('terrain' | 'tiles'), bake, haloLayer, city, life, info(), dispose()}`. The env owns the city across the bay (`SLCity3D`) and the ambient life (`SLLife3D`): it creates, updates, forwards setMember / setReduced / setUser / setEdit / setQuality to and disposes them, feeds `city.reflections()` to the sea's light pillars and `life.boats()` to the sea's `uBoat[4]` wakes (MID / HIGH). The controller passes `seed` and the first `name`, calls `setEdit` on every mode change, `setUser` on a profile switch and `setConeMounts` from the Concert Stage's `cone0..2` truss anchors (null when it is not placed); with an older env (no `setEdit`, no `env.city` / `env.life`) it hosts the city and the life itself.
- **Characters**: `SL3D.makeRig / makeAvatar / makeWand / makeFanBlob` as documented in `models-characters.js` (`rig.play(clip, t, opts)`, `petPose.mixPose`, `rig.setShow(k)`).

## 6. Game 3D views (wave C)
- File `world/games/<game>-3d.js` (+ optional helper modules next to it) is an **ES module** exporting `create(mid, opts)` per §2. `import * as THREE from 'three'` (same module instance as `opts.THREE`).
- Shared assets: `const SL3D = window.SLIsland3D ? await window.SLIsland3D.ensure() : null` (if `window.SLIsland3D` is missing, inject `world/island3d/stage.js?v=<SL_WORLD_VER>` once and then call ensure). Use `SL3D.makeRig(petId, acc, SL3D.tier)` for the child's pet (from `opts.cfg.pet`), `SL3D.make('kart_<x>')`, `SL3D.makeWand / makeFanBlob / makeAvatar`, `SL3D.kit(tier)` for primitives and the shared toon look. If `SL3D` or a function is missing, fall back to simple primitives in the same locked colours.
- Renderer: `L = SL3D && SL3D.lease ? SL3D.lease('game', {onRevoke, onResume, onLost, onRestored, onFail: r => opts.onFail(r)}) : null`. Do NOT call `L.start()` — the game shell drives frames: render yourself in `view.frame()` with `L.renderer.render(scene, camera)`; `view.canvas = L.canvas`; `view.resize(w, h)` → `L.resize(w, h)`; `view.dispose()` → dispose your scene objects and `L.release()` (hands the renderer back to the island). With no lease, create your own renderer via `SL3D.createRenderer` or `new THREE.WebGLRenderer` with the tier's settings.
- Read only `round.state` / the logic's documented read-only fields and drain `round.events` each frame; never mutate logic. Interpolate with `alpha`. Keep 60 fps on a 2019 iPad within the games budget (`SL3D.budget`). Honour `opts.reduced`. Results/menus: the shell calls `frame(round|null, dt, 0, phase, 0)` at ~30 fps — render an attractive idle/menu scene (e.g. stage-cam orbit) for those phases.

## 7. Changes after the independent review (2026-10-03)
- `a.pets.perform(kind, uid)` → lead seconds when a pet is coming; **0 or negative = no pet** (models treat falsy/negative as "no pet"). island3d's adapter maps actors.js' -1 to 0.
- Mount `on` hooks gain optional `dragCancel()`; `dragEnd()` now always means a real release. Without `dragCancel`, a cancelled drag sends `dragCell(startX, startY)` and leaves placement open.
- Gestures: a tap may last up to 1 s; a long-press (450 ms) shows the name bubble only; a still **hold** of 1 s frames the item (play mode).
- Context loss: restored losses never count; an unrestored/thrashing loss = 2D for the session; 3 strikes in 30 min are remembered (`slIsland3D` record). The shell honours the stage's 2D verdict (`SLGameShell.verdict2d`) before opening any game view, caps play rendering at ~60 fps, idles at ~30 fps, and runs a frame watchdog (`fail3d('slow')` after sustained <20 fps).
- Music: `SLMusic.gameEnabled(track)` / `setGameEnabled(track, on)`; the beat game ('course') has its own music toggle (localStorage `slMusic:course`, default ON) independent of the island 🎵. Island music only plays while My Island is visible and no game is running.
